# Growing Gallery Support

## Contact

For support, feature requests, or bug reports:

GitHub Issues:
https://github.com/BeardedNerd3D/Growing-Gallery/issues

## Common Support Topics

### My artwork is missing

Verify:

- Artwork is not archived
- Correct child profile selected
- iCloud synchronization has completed

### Voice Memories are not recording

Verify:

- Microphone permission is enabled
- Device microphone is functional
- iOS microphone access has not been restricted

### Photos are not saving

Verify:

- Camera permissions are enabled
- Storage space is available
- iCloud storage is available if synchronization is enabled

### Sync Issues

Growing Gallery uses the user's personal iCloud account.

The developer cannot access synchronization data.

Verify:

- Device is signed into iCloud
- iCloud Drive is enabled
- Internet connectivity is available
