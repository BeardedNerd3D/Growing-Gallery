# Features

## Child Profiles

Organize artwork by child.

## Artwork Library

Capture and organize artwork photographs.

## Stories

Save the story behind each piece.

## Voice Memories

Record audio memories attached to artwork.

## Albums

Group artwork into themed collections.

## Art Books

Create keepsake books from artwork.

## Search & Filtering

Find artwork quickly using search and filters.

## Private iCloud Sync

Keep your collection synchronized across devices using your personal iCloud account.
